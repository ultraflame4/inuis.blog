# API Reference

All API routes are prefixed with `/api`.

## Overview

| Group | Description |
|---|---|
| App Meta | Application metadata |
| OIDC Auth | Login flow via external providers |
| Current User (`/api/me`) | Authenticated user actions (posts, profile, sessions) |
| Public Posts | Read published posts |
| Public Users | Browse a user's published posts |
