## Compile and Run
Clone and compile the project first.
```
git clone https://github.com/ultraflame4/inuis.blog .
just build-x
```

## First Startup

1. On first startup, the server generates a **single-use invite code**.
2. Use this code to sign up as the first **admin user**.

Once an admin exists, the invite-code requirement depends on your [invite-only setting](05-user-management.md#invite-codes).


Check the logs for your one-time invite code, then visit `http://localhost:8080`.
